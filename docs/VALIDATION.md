# 迁移包整理时的校验

以下检查在源服务器使用现有Python 3.11实验环境执行，没有加载模型权重、使用GPU或启动实验。

| 检查 | 结果 |
|---|---|
| 新服务器路径配置、独立输出保护、含空格路径及启动参数转发 | 4项测试通过 |
| 原始GHOST、ST-GHOST及模拟启动控制 | 34项测试通过 |
| 可微分图像反馈、21条件优化、VAE归一化、SSIM、快照与断点 | 23项测试通过 |
| 复制到新的临时目录后导入两个第三阶段入口 | 通过，使用迁移包自己的代码 |
| 新目录下生成配置与原始GHOST实现身份 | 通过 |
| 历史2000张清单重新抽样得到原1000张，核对原图SHA-256 | 通过 |
| 导入所需的本地Python模块完整性 | 通过 |
| 新路径配置及输入导出文件中的旧服务器绝对路径 | 未发现 |
| 包中的权重、压缩归档、账号token及私钥 | 未发现 |
| 补入的原始投影器训练、问答验证源码与源项目逐字节比较 | 通过 |
| 原始投影器训练及问答验证入口`--help` | 两个入口均通过，未加载模型 |
| 投影器训练说明中的本地文档与代码链接 | 通过 |

测试时临时引用了源服务器的Python环境，测试结束后已移除该引用。迁移包不包含虚拟环境和测试生成的运行输出。

下载后可用`python tools/verify_bundle.py`检查文件校验值、Python语法和历史样本清单。在新服务器安装环境后，可按README重复上述单元测试。

这些检查验证文件整理和配置迁移；没有验证新服务器依赖安装、真实GPU运行、显存容量或新的受害模型接口。新模型仍需按`VICTIM_ADAPTATION.md`适配与试跑。
